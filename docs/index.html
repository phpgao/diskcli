diskcli

多网盘命令行工具

用 Go 编写,夸克网盘首发。文件管理、分享、转存与并发分片上传,一条命令搞定。

快速安装 在 GitHub 查看

核心能力

文件管理

浏览、复制、移动、重命名、删除与搜索,ls / cp / mv / rm 一应俱全。

分享与转存

创建分享链接、分页列出我的分享、取消分享,以及把别人的分享一键转存到本地目录。

并发分片上传

大文件自动分片、多线程上传,基于 backoff/v5 的指数退避重试,网络抖动也能续传。

安装

方式一 · go install

需要本地已安装 Go 1.22+。

# 安装最新版到 $GOPATH/bin
go install github.com/phpgao/diskcli@latest
方式二 · 从源码构建

克隆仓库后本地编译。

# 构建并放到 ./dist
git clone https://github.com/phpgao/diskcli
cd diskcli && go build ./cmd/diskcli
配置

在 ~/.diskcli/config 写入 qk_cookie,或用环境变量 QK_COOKIE 覆盖;多账号用 [account.<name>] 段 + DISK_ACCOUNT 切换。

快速上手

列出我的分享(分页)
# 默认第 1 页,需要更多自己传 --page
diskcli share list --page 1 --page-size 20
转存别人的分享
# 把分享链接保存到网盘 /dest 目录
diskcli share save https://pan.quark.cn/s/xxxx /dest
多账号切换
# DISK_ACCOUNT 选择 [account.svip] 段
DISK_ACCOUNT=svip diskcli share list
